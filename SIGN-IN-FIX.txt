CHILLAX CAFÉ POS — Sign-in help
================================

The login supports 4–6 digits: enter the whole PIN and then tap Sign in,
or press Enter on the keyboard.

Default PINs for a new Firebase setup:
 Cashier: 0000
 Admin:   1234

Existing PINs stored in Firestore have NOT been reset.

If login cannot reach Firebase:
 1. Run from localhost via Python http server or VS Code Live Server.
 2. Check Firebase Authentication > Sign-in method > Anonymous enabled.
 3. Check Authorized domains and Firestore database availability/rules.
 4. Check that the device has working Internet access.

Note: the shared PIN screen is not real Firestore server-side access control.
Read the Firebase security warning in README.md before deploying publicly.
